# 三问多目标与工程邻域试验（2026-09-26）

本目录研究如何在题目原图与硬件规则下，同时设计切图、分核和核内顺序。Makespan 为首要目标，额外 DDR 搬运为次要目标；第三问的 L2 命中率用于机制解释和弱偏好。沿用上一版已检查的图解析、合法性校验和部分拓扑带构造，但本轮参数只用本轮开发标签拟合，每张图的候选重新从该图生成，不继承旧方案或得分。**这是方法开发证据，不是新的 100 图正式成绩。** 原有已冻结结果不因本目录的试验而改写。

问题一、二的 1 核曲线点使用题目规定的整图单核基准，单核加速比为 1；优化搜索仅针对 2—5 核。第三问的 1 核无／有 L2 对照可用同一整图方案比较，无须单核搜索。

本轮实测：

| 检验 | 结果 | 解释边界 |
|---|---:|---|
| 新邻域开发与诊断标注 | 192／192 份通过原版执行；48 组中 14 组存在更快邻域 | 事后最好候选，不等于求解器成绩 |
| 冻结后新两图验收 | 48／48 份候选通过；12 组中 1 组被选中并提速 4.01%，0 组退步 | 两图的局部结果，非全量保证 |
| 隔离改名输入复现 | 12／12 份选定方案哈希一致 | 证明本试验的最终生成与原版验收分离 |
| 提前停止的多核结构筛查 | 186／186 组结构合法，覆盖 15 张完整图和第 16 张的部分核数 | 未完成 100 图；不代表原版执行通过 |

原始解析分数在 48 组中只有 3 组改善、8 组退步，故它不能直接替代正式选择器。开发图上的容量风险门槛也偏保守：留一图时没有选出替换。应先改进预测与邻域，再考虑全量评估；不应把这版的两图结果外推成三问成绩。

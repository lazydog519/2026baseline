# 图表设计与数据依据

全部使用 Python / matplotlib。正文使用统一黑白灰、宋体中文和衬线数学字体，输出 PNG（400 dpi）、矢量 PDF、SVG；正文宽度约 170 mm，图内字号 8–10 pt。每图回答一个建模或证据问题，不生成装饰图。

| 图 | 主要问题 | 依据与统计单位 |
|---|---|---|
| 2-1 | 三问为何逐层增加机制、输入与验收如何分离 | 题目规则及实际求解流程；示意图无测量含义 |
| 5-1 | 100 图的规模、独立性和路径有何差异 | 原始输入摘要对应的结构 CSV；一图一点 |
| 6-1 | 问题一随核数和连通性如何变化 | 官方 400 行；每核100图 |
| 6-2 | 结构扩展相比分量装箱改善哪些输入 | 同场景五核100份正式方案和100份已完成对照 |
| 7-1 | A/B 的边界和数据复用区别 | 题目规则示意，不绘制假时间 |
| 7-2 | 两场景总体时间、搬运如何变化 | 相同图、核数，使用各自方案 |
| 7-3 | 搬运减少能否解释完成时间变化 | 五核逐图配对＋官方额外搬运分解 |
| 8-1 | L2 数据路径及 FIFO 插入为何具有时序性 | 官方规则示意 |
| 8-2 | 场景 B 更换方案与开启 L2 的两层效果 | 第二问400行、第三问500组开关配对 |
| 8-3 | 高命中是否一定加速、张量何时驻留 | 100图配对散点＋case080真实FIFO事件 |

图6-2、7-3不以去除退步点美化效果。分组和选例规则写入图注；示意图与实测图分别说明。每张图生成后检查裁边、文本重叠和灰度辨识，PDF以逐页预览核对。

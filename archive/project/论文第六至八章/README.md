## 阅读版与 LaTeX

PDF 阅读版由 LaTeX 章节的同源转换文件生成，公式通过 MathJax 排版，图表引用全部解析。它用于审阅章节内容；队伍模板中的最终字号、分页和目录需要合并后用 XeLaTeX 编译检查。本次未将 HTML 阅读版冒称为队伍模板编译产物。

`paper.tex` 是包含三个章节及图件的多文件 LaTeX 工程，不依赖在线图片。阅读版 HTML 已保存渲染后的公式 SVG，随本目录图件可离线打开。

## 重建

在本目录运行，Python 需要 matplotlib、numpy；Node 需要 marked、playwright 和可用的 Edge。绘图只读冻结数据，不运行求解或官方评估。

```text
python chapter8_figures.py
python build_readable.py
node render_readable.js
node render_readable.js 第八章_问题三_阅读版
```

首次生成 HTML 公式需要加载 MathJax；完成后保存为离线版本。第六、七章图件及其数据保持原稿，原绘图脚本位于相邻的 `论文第六七章` 目录。

图 8-1 为题目规则示意；图 8-2 来自全部 500 组配对验收；图 8-3 的散点包含全部 100 个五核结果，驻留轨迹选取缓存加速比最大的 case_080，选取规则和原始张量标识已记录，未对观察值平滑、删点或补造。

正式结果只来自 `full5_v2/` 与 `full1to4_v2/`。两组目录共 500 份新生成的方案，每份分别接受无 L2 和只读 L2 的原版评估。`full5/`、`confirmation/`、`confirmation_v2/`、`development_*` 是开发记录，不与最终结果逐例混选。

五核的逐图平均加速比是 **4.193923**；问题二冻结版为 **3.952170**。同一份第三问方案开关 L2 的五核平均耗时比为 **1.036819**。前两者还包含调度方法差异，不能全部归因于 Cache。100 图参与过开发诊断，这些数字不代表完全未见数据上的泛化成绩。

解压代码包后的运行接口：

```text
python solver.py data/case_001.json -n 5 --config data/config.txt -o data/case_001_multicore_res.json --report 本次诊断.json
```

单核不执行候选搜索；因题目要求比较 1～5 核的 Cache 指标，保留固定单核方案的配对验收。

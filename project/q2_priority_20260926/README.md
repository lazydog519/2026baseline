# 问题二：同核合并条件下的独立求解

权威提交版本为 [`final_v2/`](final_v2/)。顶层 `pilot.csv`、`selected_sample.csv` 和 `full_metrics.csv` 记录开发诊断，不作为最终成绩；`final_v2/full_metrics.csv` 与 `final_v2/full_summary.json` 才是最终 100 图、2～5 核的官方验收文件。题目原图与 `config.txt` 均未修改。

最终版 100 图、2～5 核共 400 组全部通过原版场景 B 评估，零失败。按题目单核基准计算，2、3、4、5 核平均加速比分别为 **1.935754、2.745234、3.464548、3.952170**。五核值位于本轮预期区间内；这一数值是完整官方验收结果，不是小样本或代理预测。

五核推理的图读取与求解计时中位数为 0.308 秒，100 图最大为 4.170 秒；这一口径不含 Python 进程启动和单独的官方验收耗时。原始逐例计时保存在 `final_v2/full_plans/*_generation.json`。

场景 B 把一核上的全部子图合并为一个 Task。同核数据通过私有 L1/UB 复用；跨核数据须写回 DDR、读取 DDR，并等待固定 500 cycle 同步。求解器以双 Pipe 负载、图上跨核关键路径和 DDR 总流量构成时间代理，再用张量在核内的静态存活区间构成缓存压力项。它只在分量装箱、宽度谷、两种数据感知深度带和固定深度带五类方案中选择。缓存压力是候选排序量，不冒充附件 Step 2 的准确溢出量；正式 Makespan、额外搬运及容量合规性均由冻结后原版评估给出。

在开发诊断中，静态超容量风险为正的 28 个五核方案，其实际插入的溢出搬运量与静态风险字节的比值中位数约为 10.54。最终版本将风险系数统一固定为 10；这是对给定图集合的全局标定，没有任何逐例系数或结果查询。由于标定和正式验收使用同一批 100 个给定图，不能将最终均值宣称为独立分布外性能。旧版本保留供复核，但不应引用为当前提交指标。

独立推理示例，`-n` 取 2～5：

```powershell
python final_v2/solver.py 输入图.json -n 5 --config 原版config.txt -o 输入图_multicore_res.json
```

`final_v2/submission_q2.zip` 仅含五个纯推理源文件，不包含官方评估器、历史方案或成绩。`final_v2/package_verification.json` 记录在隔离目录改名输入后的方案复现。单核仅使用题目规定的整图基准，加速比记为 1，不进行多核搜索。第六章正文和可直接引用的 LaTeX 公式见 [`../论文第六章/`](../论文第六章/)。

正式运行先用 `final_v2/full_generate.py` 在每个图、每种核数的新进程中生成方案并记录哈希，完成后才运行 `final_v2/full_audit.py`。推理源码不导入官方评估器；验收脚本单独导入原版场景 B 评估程序，若任何组合失败则保留失败记录，不删例或改配置。

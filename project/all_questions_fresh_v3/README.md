# 三问独立生成试验（2026-09-26，v3）

本目录记录一次完整的开发、冻结与验收：9 个开发图上获取 342 份官方标签，拟合三个场景的全局选择权重；随后在隔离进程中对 6 个留出图生成并冻结 180 份方案，最后才调用原版程序验收。180 份方案均通过，官方 114 个文件及冻结的推理源码哈希一致。这里的均值只代表六图，不是 100 图正式成绩。

上版差距大，主要因为仅装箱弱连通分量，并附加了题目没有要求的核心依赖无环限制。对大连通分量，这会阻止合法切分和跨核流水。本版保留分量装箱作对照，恢复从当前图拓扑层、汇合点与输出祖先关系构造的少量切分候选；每次推理只读取当前图、固定硬件配置和本版冻结参数。官方评估器仅在开发标注及冻结后验收中使用，不参与最终方案生成。

六图五核加速比算术平均为：问题一 3.429660，问题二 3.645733，问题三 3.968297。与同六图历史方案配对后，历史问题二、三仍略优；旧版的合法切分、局部重排与同核复用值得继续研究，历史在线评估器择优不能直接搬入当前提交口径。详见[模型与实验说明](三问模型与实验说明.md)及[公式](模型与算法公式.tex)。


## 输入图数据与三问统一建模

100 个官方输入图的预处理画像、描述统计、多目标公式和 8 张输入侧分析图见[三问问题重述、数据分析与多目标模型](三问问题重述_数据分析与多目标模型.md)。图表由 describe_and_plot_inputs.py 复现，分别提供 PNG 和 PDF；数据哈希/profile 全部通过核对。该描述分析不读取评估结果。

文件用途：

- `submission_solver.zip`：最终独立推理包，仅含 `solver.py`、`mechanism.py`、`stage_candidates.py`、`model.json`。
- `manifest.json`、`generation_freeze.json`：输入/官方文件与推理源码哈希、训练/留出划分、全部方案哈希。
- `training_labels.json`、`fit_report.json`：仅开发阶段的官方标签与本版拟合结果。
- `summary.json`、`validation_results.json`、`metrics.csv`：留出验收结果；`boundary_audit.json` 核对 342 份开发方案的边界搬运字节。
- `figures/`：两张由验收数据生成的 PNG/PDF，以及绘图源数据。
- `structural_screen.json`：100 图上的不调用评估器的结构检查；只证明节点覆盖和顺序依赖，不代替原版执行验收。

复现顺序为 `experiment.py prepare`、`train`、`generate`、`accept`、`publish.py`。已冻结目录不应重跑 `prepare`/`generate` 覆写证据；如需修改求解逻辑，请复制代码建立新版本，再重新抽取开发与留出图。

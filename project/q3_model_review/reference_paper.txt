以及 “ 核内核间同步开销 ” 三大核心物理矛盾，本文提出了一套兼具严格理论保证与极速收敛特性的宏 数 据 流 分 量 解

针 对 问 题 一 （ 场 景  A 无 硬 件 同 步 机 制 ） ：  建立共享  DDR 物理带宽的流体动力学方程，严格数学推导了并发搬
运对有效带宽的二次方延时拖慢机理。通过对官方  100 个基准计算图的代数图论谱分析，证明了  84% 的算例拉普拉斯
矩阵零特征值重数  dim ker (𝐿)=𝐾，天然由多个互无中间依赖的弱连通分量构成。在此基础上，提出分 量 级 无 损 装 箱
模 型 （ Zero-Cut LPT Bin-Packing ） ，将弱连通分量作为原子装箱物品，严禁切割分量内部，采用多维最长处理时间
优先启发式算法分配至各物理核心。在理论上证明了该策略达成跨 子 图 割 集 通 信 量 严 格 为  0 、 系 统 新 增 额 外  DDR
搬 运 量 恒 为  0，彻底消灭了  1000 周期跨核等待气泡，并根据  Graham 定理推导其近似比上界为  4/3 。实验表明，本文
算法在  1~5 核下的平均加速比分别为  1.00x, 1.93x, 2.78x, 3.36x, 3.81x，在多连通分量算例上  4 核加速比达到  3.95x（逼

针 对 问 题 二 （ 场 景  B 具 备 硬 件 同 步 机 制 ） ：  深入剖析评测系统  Step2 的  Belady MIN 换入换出执行机理，构建

1 .1  系 统 架 构 与 执 行 模 型
通用神经网络处理器（ NPU ）是支撑现代大模型推理与训练的高效专用计算架构。典型  NPU 包含多个同构  AI 计算核心
与共享存储体系。每个物理核心内部配置有专门负责矩阵乘法运算的  Cube 单元（PIPE_M）、矢量张量运算的  Vector 单元
（PIPE_V），以及两级高速片上私有  SRAM 存储 ——L1 Buffer （ 512 KB ）与  Unified Buffer （ UB, 128 KB ）。核间通过共享
核外高带宽内存（ DDR, 物理带宽  60 bytes/cycle ）以及在高级架构中引入的共享只读  L2 Cache （容量  1 MB, 独立命中带宽
250 bytes/cycle ）进行数据交换。
待执行的神经网络编译中间表示为宏 数 据 流 图 ，其在图论上表述为有向无环二部图（ DAG ） G = (T U O, E) ，其中包含
张量节点集合  T 、算子操作节点集合  O 以及有向依赖边集合  E 。在单核内部， Cube 与  Vector 单元支持乱序并发执行，数据
搬运开销能够被深度流水掩盖；而在跨核心之间，必须承受严格的物理通信同步延迟。

1 .2  多 核 调 度 三 大 物 理 矛 盾 分 析
矛 盾 一 ： 多 核 计 算 并 行 度 与  DDR 总 线 争 用 的 矛 盾 。  将单图切分为多个子图分布至多核可释放计算吞吐，但若切分
破坏了密集数据流，将产生大量跨子图  DDR 搬运。由于  DDR 总物理带宽严格受限为  60 bytes/cycle 且由所有活跃操作公平
均分，过多的并发搬运会导致严重的相互拖慢效应。
矛 盾 二 ： 片 上 私 有 缓 存 容 量 与  Belady 换 入 换 出 雪 崩 的 矛 盾 。  私有  L1 与  UB 空间极其宝贵。在  Step2 核内调度中，
一旦瞬时活跃张量超出物理上限，系统将被迫执行  Belady MIN 换出至  DDR ，并在后续消费时重新换入，导致总线停顿剧烈
放大。
矛 盾 三 ： 同 核 流 水 掩 盖 与 跨 核 同 步 气 泡 的 矛 盾 。  场景  A 下跨子图依赖需  1000 周期等待，场景  B 下虽支持轻量级同
步，但仍需  500 周期硬件信号延迟。若切图不当，核心将长期处于等待前驱子图完成的空闲气泡状态。

二 、  模 型 假 设 与 符 号 说 明
2 .1  基 本 假 设
1. 硬 件 同 构 性 假 设 ：  各  AI 核心的计算流水线、指令吞吐率及  L1/UB 容量完全相同；
2. 执 行 确 定 性 假 设 ：  计算图结构静态固定，算子执行周期与张量字节数均为静态非负整数；
3. DDR 流 体 公 平 共 享 假 设 ：  所有访问共享  DDR 的在途搬运操作按当前活跃并发数严格均分  60 bytes/cycle 总物理带宽；
4. L2 Cache 先 进 先 出 淘 汰 假 设 ：  共享  L2 Cache 容量为  1,048,576 字节，仅服务于  COPY_IN 操作，遵循严格的  FIFO 单向淘
汰规则；
5. 无 死 锁 保 因 果 性 假 设 ：  调度算法生成的子图商图必须为严格  DAG ，且全局执行依赖不存在等待环路。

def _decompose_components(self):
    """ 利用无向图  BFS 搜索得到非搬运计算操作的全部弱连通分量  (84% 算例特性 )"""
    adj = defaultdict(set)
    for u in self.non_copy:
        for v in self.op_succs[u]:
            adj[u].add(v); adj[v].add(u)
    visited, self.components = set(), []
    for u in sorted(self.non_copy):
        if u not in visited:
            comp, q = [], [u]; visited.add(u)
            while q:
                curr = q.pop(0); comp.append(curr)
                for nbr in adj[curr]:
                    if nbr not in visited:
                        visited.add(nbr); q.append(nbr)
            self.components.append(sorted(comp))
    self.comp_stats = [
        {'nodes': c, 'cycles': sum(self.op_by_id[u]['cycles'] for u in c)}
        for c in self.components
    ]
def solve_lpt(self, num_cores=4):
    """ 多维负载均衡  LPT 装箱调度：割集通信量严格为  0 ，消灭所有跨核等待 """
    sorted_comps = sorted(self.comp_stats, key=lambda x: x['cycles'], reverse=True)
    core_loads = [0] * num_cores
    core_assignments = [[] for _ in range(num_cores)]
    for c_stat in sorted_comps:
        best_core = min(range(num_cores), key=lambda c: core_loads[c])
        core_assignments[best_core].append(c_stat['nodes'])
        core_loads[best_core] += c_stat['cycles']
    node_to_subgraph, core_schedules = {}, [[] for _ in range(num_cores)]
    for c in range(num_cores):
        core_schedules[c].append(c)
        for comp in core_assignments[c]:
            for u in comp: node_to_subgraph[str(u)] = c
    return {'node_to_subgraph': node_to_subgraph, 'core_schedules': core_schedules}

"""
================================================================================
2026 年中国研究生数学建模竞赛  A 题（华为专项）
通用神经网络处理器下的多核调度问题
模块  1 ：问题一（场景  A 无同步机制）数学建模与求解算法
================================================================================
模型原理：
1. 宏数据流图图论建模：二部图向压缩  Op-Op DAG 转换；
2. 弱连通分量（ Weakly Connected Components ）识别与分离；
3. 零割集通信约束下的多目标瓶颈极小化装箱模型  (Min-Max Multi-Resource Bin Packing) ；
4. 最长处理时间优先（ LPT ）启发式求解与严格保  DAG 因果性拓扑调度。
"""
import json
import os
import sys
from collections import defaultdict
EXCLUDED_COPY_TYPES = {'COPY_IN', 'COPY_OUT'}
class Problem1ModelSolver:
    """
    问题一数学模型求解器：
    决策变量：
      phi(u): 节点  u 所属的子图编号  (sgid)
      pi_c: 核心  c 上的子图执行次序
    目标：
      Min Makespan = max_{c} Load(c) + Contention(DDR) + Sync(Wait)
    约束：
      - 割集通信量最小化（零割集通信目标）
      - 子图商图  G_S 严格无环
      - 同核子图序列不违反拓扑因果依赖
    """
    def __init__(self, graph_json):
        self.raw_graph = graph_json
        self.ops = graph_json.get('ops', [])
        self.tensors = graph_json.get('tensors', [])
        self.edges = graph_json.get('edges', [])
        
        self.op_by_id = {op['id']: op for op in self.ops}
        self.tensor_by_id = {t['id']: t for t in self.tensors}
        
        # 提取待调度的核内非  COPY 计算算子
        self.non_copy = {
            op['id'] for op in self.ops
            if op.get('op') not in EXCLUDED_COPY_TYPES
        }
        
        self._build_op_dag()
        self._decompose_components()
        self._extract_chains()
    def _build_op_dag(self):
        """ 将  Op-Tensor 二部图转换为直接的  Op-Op 依赖  DAG"""
        producers = defaultdict(set)
        consumers = defaultdict(set)
        direct_edges = []
        
        for e in self.edges:
            s, t = e['source'], e['target']
            s_is_op = s in self.op_by_id
            t_is_op = t in self.op_by_id
            if s_is_op and not t_is_op:

=== PAGE 17 ===
2026年中国研究生数学建模竞赛参赛论文
— 17 —
                producers[t].add(s)
            elif not s_is_op and t_is_op:
                consumers[s].add(t)
            elif s_is_op and t_is_op and s != t:
                direct_edges.append((s, t))
                
        self.op_succs = defaultdict(set)
        self.op_preds = defaultdict(set)
        
        for t, p_set in producers.items():
            for p in p_set:
                for c in consumers.get(t, ()):
                    if p != c and p in self.non_copy and c in self.non_copy:
                        self.op_succs[p].add(c)
                        self.op_preds[c].add(p)
                        
        for s, t in direct_edges:
            if s in self.non_copy and t in self.non_copy:
                self.op_succs[s].add(t)
                self.op_preds[t].add(s)
    def _decompose_components(self):
        """ 寻找弱连通分量  (Weakly Connected Components)"""
        adj = defaultdict(set)
        for u in self.non_copy:
            for v in self.op_succs[u]:
                adj[u].add(v)
                adj[v].add(u)
                
        visited = set()
        self.components = []
        for u in sorted(self.non_copy):
            if u not in visited:
                comp = []
                q = [u]
                visited.add(u)
                while q:
                    curr = q.pop()
                    comp.append(curr)
                    for nbr in adj[curr]:
                        if nbr not in visited:
                            visited.add(nbr)
                            q.append(nbr)
                self.components.append(sorted(comp))
                
        # 统计各分量的计算负载  (Cycles) 与算子类型
        self.comp_workload = []
        for idx, comp in enumerate(self.components):
            cycles = sum(self.op_by_id[u]['cycles'] for u in comp)
            m_cycles = sum(self.op_by_id[u]['cycles'] for u in comp if self.op_by_id[u].get('pipe') == 'PIPE_M')
            v_cycles = sum(self.op_by_id[u]['cycles'] for u in comp if self.op_by_id[u].get('pipe') == 'PIPE_V')
            self.comp_workload.append({
                'id': idx,
                'nodes': comp,
                'cycles': cycles,
                'm_cycles': m_cycles,
                'v_cycles': v_cycles,
                'op_count': len(comp)
            })
    def _extract_chains(self):
        """ 提取汇聚规约树的并行链结构 """
        self.roots = sorted([u for u in self.non_copy if len(self.op_preds[u]) == 0])
        self.chain_ops = set()
        self.root_to_chain = {}
        for r in self.roots:
            curr = r
            chain = []
            while curr in self.non_copy and len(self.op_preds[curr]) <= 1 and (curr == r or len(self.op_preds[curr]) == 1):
                chain.append(curr)
                if len(self.op_succs[curr]) == 1:
                    nxt = next(iter(self.op_succs[curr]))
                    if len(self.op_preds[nxt]) > 1:
                        break
                    curr = nxt

                else:
                    break
            self.root_to_chain[r] = chain
            self.chain_ops.update(chain)
        self.reduction_ops = sorted(list(self.non_copy - self.chain_ops))
    def solve(self, num_cores=4):
        """
        根据核心数  num_cores 求解最优切图与调度方案
        """
        if num_cores <= 1:
            eligible = sorted(self.non_copy)
            return {
                'node_to_subgraph': {str(u): 0 for u in eligible},
                'core_schedules': [[0] if eligible else []]
            }
        # 策略  A ：若弱连通分量数  >= 核心数，应用分量级零割集多机  LPT 装箱
        if len(self.components) >= num_cores:
            sorted_comps = sorted(self.comp_workload, key=lambda x: x['cycles'], reverse=True)
            core_loads = [0] * num_cores
            core_bins = [[] for _ in range(num_cores)]
            
            for comp in sorted_comps:
                # 贪婪选择当前累积负载最小的核心  (LPT 核心步 )
                best_core = min(range(num_cores), key=lambda c: core_loads[c])
                core_bins[best_core].append(comp['nodes'])
                core_loads[best_core] += comp['cycles']
                
            node_to_subgraph = {}
            core_schedules = [[] for _ in range(num_cores)]
            
            for c in range(num_cores):
                core_schedules[c].append(c)
                for comp_nodes in core_bins[c]:
                    for u in comp_nodes:
                        node_to_subgraph[str(u)] = c
                        
            return {
                'node_to_subgraph': node_to_subgraph,
                'core_schedules': core_schedules
            }

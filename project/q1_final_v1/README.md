# Q1 Final v1

Full Q1 method, result table, three independently reproducible figures and solver package are in this directory.

- Main report: `技术思路稿-问题一全量重跑.md`
- Results: `results/per_case_metrics.csv`, `results/aggregate.json`, `results/full_summary.json`
- Figures: `figures/` (PNG/PDF/SVG plus Python renderer)
- Solver: `solution/`

Run from repository root: `python3 project/q1_final_v1/solution/run_q1_final.py --workers 2`. Use `--cases 1 2 --cores 2 5` for a small reproducibility check. Inputs and the unchanged official evaluator are in `project/official/`.

# 问题三独立求解：结果口径

- `final5/aggregate.json` 和 `final5/audit_progress.csv` 是已完成的 100 例、五核独立复核结果。逐例加速比的算术平均为 **4.395999301225474**，缺失 0 例；100 份方案均由题目原版有 L2 / 无 L2 评测器重新计算，官方附件 114 个文件校验未变。
- `full5/` 保存五核工程化第一阶段原始运行；`fusion_full/` 与 `fusion_full_late/` 合计保存 100 例的融合后方案及结果。这些目录是复现实验的逐例记录。
- `submission_q3.zip` 是不读取既往方案的独立求解代码包；`package_verification.json` 记录改名输入的隔离复现。参数和随机种子随代码包固定。
- `模型与算法公式.tex` 和项目根目录的 `技术思路稿-问题三独立求解.md` 提供论文方法说明。
- `full1to4/`、`fusion_full1to4/` 仍在运行，**不能**作为 1～5 核正式均值引用；它们完成后须经 `solution/q3_fusion_audit.py` 独立复核，权威统计写入 `final/`。

所有加速比以题目给定的每例原始单核参考周期为分母，先逐例求比再对 100 例取算术平均；“缓存收益”是在同一最终方案上比较有/无 L2，避免混入调度差异。
